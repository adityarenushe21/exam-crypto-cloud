# Security policy

This is a student prototype (B.Tech capstone, MIT World Peace University). It has not had a
security audit and must not be used to protect real examination papers.

## Reporting a problem

If you find a security issue, please **do not open a public issue**. Report it privately through
GitHub: **Security → Report a vulnerability** on this repository. We will reply as soon as we can.

## What is never in this repository

Private keys, passphrases, user accounts, AWS credentials and generated data are excluded by
`.gitignore`. If you ever see a secret here, report it as above.
